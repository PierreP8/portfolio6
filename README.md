# Mounia Lanou portfolio — GitHub Pages

This is a static homepage, ready for GitHub Pages.

## Publish it

1. Create (or open) the GitHub repository for the portfolio.
2. Upload the **contents** of this folder — `index.html`, `.nojekyll` and `assets/` — to the repository root.
3. In GitHub, open **Settings → Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.

The navigation links to the future pages (`campaigns.html`, `more-works.html`, `about.html`) are intentionally already wired. They will work once those pages are created.
